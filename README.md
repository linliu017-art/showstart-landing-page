# ShowStart Landing Page Concept

一个围绕现场演出发现、购票和电子票夹体验设计的秀动 App 非官方产品落地页概念。

## 在线预览

项目发布后可通过 GitHub Pages 直接访问。

## 特性

- GSAP + ScrollTrigger 驱动的页面级滚动叙事
- Swiper Coverflow 演出轮播
- 自动轮播、拖拽、鼠标滚轮、箭头与分页切换
- 响应式桌面和移动端布局
- `prefers-reduced-motion` 动效降级
- 无构建步骤，直接打开 `index.html` 即可运行

## 本地预览

直接打开 `index.html`，或使用任意静态文件服务器运行项目。

页面通过 CDN 加载 GSAP、Swiper，并使用 Unsplash 远程示例图片，因此预览时需要网络连接。
